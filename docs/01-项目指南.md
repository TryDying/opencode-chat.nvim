# 项目指南

## 项目定位

`opencode-chat.nvim` 是一个面向 Neovim 的轻量 opencode 集成插件。第一版目标是用最小功能替代 `CopilotChat.nvim` 的常用问答入口：在编辑器中打开 opencode TUI，并把当前文件或选区作为上下文追加到 opencode 输入框。

## MVP 范围

第一阶段只实现基于 opencode TUI 的集成：

- Normal 模式通过 `<M-->` 打开或隐藏 opencode TUI。
- Visual 模式通过 `<M-->` 追加当前选区引用。
- 同一个 Neovim 进程内复用同一个 opencode TUI/session。
- 重启 Neovim 后创建新的 opencode session。
- 追加上下文后不自动提交，用户可以继续编辑问题。

## 非目标

第一版暂不实现：

- Neovim 原生 Chat UI。
- `opencode serve` 的完整会话和消息渲染流程。
- diff apply、文件树、多 session picker、prompt templates、agent/mode 管理。
- `vim-floaterm` 后端。

## 交互方式

插件启动 `opencode --port <port>`，让 opencode TUI 运行在 Neovim 原生 floating terminal 中。Neovim 不向 terminal 直接注入按键或文本，而是通过本地 HTTP 接口：

```http
POST /tui/append-prompt
```

把上下文文本追加到 TUI 输入框。

## 文件引用格式

当前文件引用：

```text
@relative/path/to/file.lua
```

选区引用：

```text
@relative/path/to/file.lua#L10-L30
```

选区行号始终按升序输出，即使用户反向选择文本。
